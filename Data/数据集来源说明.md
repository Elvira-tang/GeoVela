# 四个数据集来源说明

采集时间：2026-11-05
坐标系统：除注明外均为 WGS84（经纬度，EPSG:4326）。高德原始数据为 GCJ-02，已按坐标偏移公式转换为 WGS84。

---

## 1. 全国天气数据

**文件**：`Weather7Days_20261105/data/china_weather_last7days.csv`（343 行，48 个城市 × 7 天）

**数据源**：Open-Meteo Historical Weather API（开放免费，无需 Key）
- 接口：`https://api.open-meteo.com/v1/forecast`
- 方法：`GET`
- 关键参数：
  - `latitude` / `longitude`：48 个省级行政区代表城市坐标
  - `daily=temperature_2m_max,temperature_2m_min,temperature_2m_mean,precipitation_sum,rain_sum,snowfall_sum,precipitation_hours,weathercode,windspeed_10m_max,winddirection_10m_dominant,sunshine_duration`
  - `timezone=Asia/Shanghai`
  - 时间范围：最近 7 天（2026-10-30 至 2026-11-05）

**字段**：日期、最高/最低/平均气温、降水量、降雨量、降雪量、降水时长、天气现象（WMO 代码转中文）、最大风速、主导风向、日照时长。

**来源可靠性**：Open-Meteo 为再分析数据（ERA5 等全球气象模型 + 站点融合），温度精度约 ±1 ℃，降水为网格估算值；不代表具体站点观测。

## 2. 无锡奶茶店 POI

**文件**：`MilkTea_Wuxi_20261105/data/wuxi_milktea_poi.csv`（1654 家，49 个品牌/独立门店）

**数据源**：高德地图 Web 服务 — POI 搜索接口
- 接口：`https://restapi.amap.com/v3/place/text`
- 方法：`GET`，需 `key`（Web 服务类型）
- 关键参数：
  - `keywords`：冷饮店、奶茶、茶饮、果茶、柠檬茶、烧仙草、手作茶 + 27 个品牌名（蜜雪冰城、喜茶、霸王茶姬、奈雪的茶、茶百道、古茗、沪上阿姨、一点点、CoCo都可 等）
  - `types=050700`（冷饮店分类码）
  - `city=无锡` / `citylimit=true`
  - `offset=25`，`page=1..N` 分页
- 按 7 个区县（梁溪 320213 / 锡山 320205 / 惠山 320206 / 滨湖 320211 / 新吴 320214 / 江阴 320281 / 宜兴 320282）分别扫描，再全国范围关键词补充，按 POI id 去重。

**坐标处理**：原始返回为 GCJ-02（火星坐标系），已用公开偏移算法转换为 WGS84，表中同时保留两套经纬度列。

**字段**：POI_ID、名称、品牌、类型、地址、省/市/区县、商圈、GCJ-02 坐标、WGS84 坐标、电话、评分、人均消费、营业时间、来源。

**已知局限**：
- 高德「冷饮店」单查询上限 200 条/次，部分密集区门店可能被截断，已用 33 个关键词交叉补充
- 剔除了咖啡店、批发部、茶馆、便利店等非奶茶门店，保留少量果茶/酸奶/柠檬茶饮品店
- 评分与电话有缺失（评分覆盖 ~95%，电话覆盖 ~85%）
- Key 已脱敏，不随数据发布

## 3. 江南大学校园地图

**文件**：`CampusMap_Jiangnan_20261105/data/jiangnan_university_campus.csv`（234 行：建筑 95 / 道路 61 / 体育休闲 34 / 设施 26 / 出入口 9 / 景点 3 / 用地 2 / 节点 4）

**主数据源**：OpenStreetMap — Overpass API
- 接口：`https://overpass-api.de/api/interpreter`（备用 kumi / nchc / private.coffee）
- 查询范围 bbox：`31.4765,120.2582,31.4943,120.2728`
- 要素类型：`building`、`highway`、`leisure`、`amenity`、`entrance`、`tourism`、`landuse`
- 几何保留为 WKT（`POINT / LINESTRING / POLYGON`）

**辅助数据源**：高德地图 POI（用于补齐建筑名称）
- 以校园中心 GCJ-02 `(120.2705, 31.4832)` 为圆心、`radius=1800` 用 24 个关键词（教学楼、图书馆、实验楼、宿舍、食堂、体育馆等）分页检索
- 仅保留落在 Nominatim 返回的「江南大学」校园多边形内的 POI
- 回填策略：全局就近匹配（大建筑 120 m / 小建筑 80 m），同 POI 不重复分配，撤销误填（快递柜、附属医院食堂等）
- 新增 OSM 未覆盖的 20 栋建筑，标记来源 `高德地图POI (GCJ-02转WGS84)`

**字段**：OSM_ID、类别、名称、类型细分、面积(m2)、长度(m)、经度、纬度、几何(WKT)、OSM 标签备注、数据来源、采集日期，**高度(m)/层数** 两列为后加。

**建筑高度来源**：OSM 仅 1 栋有 `building:levels` 标签，其余 94 栋按建筑类型估算（图书馆 8 层/28m、学院/教学楼 5 层/17.5m、宿舍 6 层/18m、体育馆 15m、食堂 10m 等），备注列标注「高度为按建筑类型估算」。

**已知局限**：
- 11 栋小型附属建筑无名称（配电房/门卫级），备注注明用途待定
- 1 处 `浩苑公寓` 与高德同名 POI 相距 700 m，需人工核对
- 校园边界取自 Nominatim「江南大学」relation，包含长广溪宾馆等校外合作建筑

## 4. 无锡地铁 + 步行网络 + 可达性

目录：`Dorm_MilkTea_Metro_Accessibility_20261105/`

### 4.1 地铁站点表 `raw/metro_stations.csv`（98 站）
- **源**：OpenStreetMap Overpass — `relation["type"="route"]["route"="subway"]`
- bbox：`31.30,119.95,31.75,120.55`（无锡全域）
- 站点提取：关系成员中 `role=stop/platform` 的节点与 way（站台），车站名规范化（去除尾随「站」，但保留「火车站」）
- 名称过滤：剔除苏州、常州同名线路（`1号线：钟南街→木渎`、`常州地铁1号线`、`苏州3/6/8号线`）
- 终站补充：OSM 关系中缺失的终点站（2 号线 梅园开原寺、安镇）用 `node["subway"="yes"]` 端点吸附（≤2.6 km）补齐
- 线路：1 号线 27 / 2 号线 22 / 3 号线 21 / 4 号线 18 / S1 号线 10
- `is_transfer`：同名站出现在 ≥2 条线路则标记 1，共 8 个换乘站（堰桥、刘潭、无锡火车站、三阳广场、市民中心、河埒口、靖海、盛岸）

### 4.2 相邻站关系 `raw/metro_edges.csv`（101 条）
- **源**：同 4.1 的 OSM 关系成员顺序
- `distance_m`：相邻站球面直线距离（Haversine，R=6371 km）
- `travel_time_min = distance / 35 km/h × 60`（估算，非官方时刻表）
- 换乘边：站内换乘步行 3.0 min，`line_id=换乘`，`direction=站内换乘`（8 条）
- `direction`：该方向终点站名

### 4.3 地铁出入口 `raw/metro_station_entrances.csv`（176 个）
- **源**：OSM `node["railway"="subway_entrance"]`
- 关联：到 450 m 内最近地铁站的 `station_id`

### 4.4 步行网络
- **文件**：`raw/walking_nodes.csv`（38885 节点）、`raw/walking_edges.csv`（43461 边）、`raw/walking_network.graphml`（9.6 MB）
- **源**：OSM Overpass，`way["highway"~"^(footway|pedestrian|path|steps|residential|service|unclassified|tertiary|secondary|living_street|cycleway)$"]`
- bbox：`31.44–31.56°N / 120.22–120.34°E`（滨湖区核心，含江南大学校园、长广溪、河埒口、蠡湖）
- 3×3 瓦片抓取，单片失败自动四分递归（深度 ≤ 2），每片缓存可断点续跑
- 节点用 `out skel qt` 降体积；边长为相邻节点球面距离；graphml 为无向图
- **覆盖局限**：1654 家奶茶店中仅 277 家落在本框内（含 250 m 吸附），框外门店未参与可达性

### 4.5 可达性结果 `processed/`
- **源**：本地计算（无外部接口），基于上述步行网络 + 地铁图用 Dijkstra / 多源 Dijkstra
- 模型参数：步行 75 m/min、进出站固定 2 min、换乘 3 min、列车商业速度 35 km/h、宿舍接驳上限 2500 m
- `dorm_station_access.csv`（45 行）：20 栋宿舍 → 最近地铁出入口的步行距离/时间
- `station_milktea_access.csv`（5850 行）：25 个站 → 277 家奶茶店出站步行
- `accessibility_results.csv`（5500 行）：20 栋 × 275 家最优全程时间，含上车站、下车站、各段耗时
- 宿舍坐标来自 `raw/jiangnan_university_campus.csv`，奶茶坐标来自 `raw/wuxi_milktea_poi.csv`（均已为 WGS84）

## 统一说明

| 项目 | 工具/语言 |
|---|---|
| 网络请求 | Python `urllib` |
| 坐标转换 | GCJ-02 → WGS84 公开偏移公式 |
